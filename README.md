# PrepWise-AI (Ongoing)
An AI-based mock interview platform for technical and HR interview preparation.

- An AI-powered mock interview platform designed to help students and developers prepare for technical and HR interviews through AI-generated questions, feedback, and performance analysis.

## Features

* AI-generated interview questions
* Technical & HR interview modes
* AI-based answer evaluation and scoring
* Interview history tracking
* Responsive and modern UI
* Authentication and session management
* Real-time feedback and improvement suggestions

## Tech Stack

* React.js
* Tailwind CSS
* Node.js
* Express.js
* MongoDB / PostgreSQL
* Gemini API
* JWT Authentication

## Status

🚧 Currently under development.
Planned features include voice interviews, coding rounds, AI follow-up questions, and detailed analytics dashboard.
